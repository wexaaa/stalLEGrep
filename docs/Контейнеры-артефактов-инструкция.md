# Контейнеры для артефактов

Исправление установлено в локальную сборку STALCRAFT 2019. Старое окно отправляло пакет установки артефакта `kldc`, но локальный обработчик сервера не поддерживал этот пакет. Он возвращал прежнее содержимое. Теперь команда обрабатывается сервером, результат сохраняется в штатном NBT контейнера и синхронизируется с клиентом.

1. Сначала исследуй найденный артефакт на станке. Неисследованные предметы в контейнер не устанавливаются — это штатное правило игры.
2. Держи контейнер и артефакт в инвентаре STALCRAFT, не в обычной панели блоков. Через F7 выбирай назначение «STALCRAFT».
3. Открой контейнер через **Shift + правую кнопку мыши** по его иконке, нажми нужный слот и выбери исследованный артефакт.
4. Для применения бонусов экипируй контейнер в **слот спины**. Просто лежащий в рюкзаке контейнер не экипирован. Изношенный контейнер, состояние артефакта и другие штатные ограничения по-прежнему влияют на характеристики.

При установке из стопки используется один экземпляр. При замене прежний артефакт возвращается в ячейку выбранного нового, если новый был один; иначе нужна свободная ячейка основного инвентаря. При извлечении тоже нужна свободная ячейка. Если места нет, сервер сообщает об этом в чате и оставляет вещи без изменений. Артефакт не выбрасывается на землю.

Исследованные свойства, метаданные, владелец, состояние, срок жизни и вложенные данные сохраняются. Транзакция сначала готовит копии и проверяет все места, затем применяет изменения. При отказе записи ячейки выполненные записи откатываются. Повторные пакетные действия с тем же номером подтверждаются без повторного выполнения. Подтверждение возвращается также при ошибке, чтобы окно не зависало в ожидании сервера.

После успешного перемещения вызывается штатное уведомление изменения инвентаря, которое пересчитывает свойства экипировки. Формулы бонусов, вместимость контейнера и число слотов не менялись. Исследование и вложение артефактов не требуют прав оператора; сервер проверяет доступ игрока к окну и ячейкам. Недоступное окно не подменяется другим.

Для игры с другом обоим нужно полностью перезапустить игру с одинаковым обновлённым файлом `classes/offline-patches.jar`. Копия файла находится рядом с этой инструкцией в outputs. Уже имеющиеся контейнеры заменять не нужно; сохранения при установке не редактируются.

Перед установкой создана резервная копия `offline-patches.before-artifact-containers-20261004-01.jar` в папке classes. Остальные исправления кейсов, баланса, спавнера, инвентарей и станка сохранены. Исходники находятся в tools/offline-artifact-containers; для обычной игры их запускать не требуется.

Проверено: JVM-верификация нового помощника и серверного обработчика; побайтная сохранность 230 других записей JAR; сохранность остальных серверных методов; подключение штатного пакета к новому обработчику. В изолированных тестах проверены установка, замена, извлечение, один экземпляр из стопки, отсутствие потери/дублирования, глубокая копия NBT и его сохранение/загрузка, штатная сумма бонусов и её исчезновение после извлечения, вызов пересчёта, подтверждение действия, повторный запрос, отказ при заполненном инвентаре, откат при отказе записи, права доступа, неизвестное окно и серверная сторона.

Тестовые адаптеры инвентаря, мира и доставки пакетов не устанавливаются в игру. Классы контейнера, артефакта, вложения NBT, исследования и расчёта свойств использовались настоящие. Полную отрисовку окна, изменение характеристик конкретного персонажа и игру по сети нужно проверить в запущенной игре; автоматически игра не запускалась.
