# Сборка: требования и важные ограничения

Потребуются совместимая локальная сборка 2019, Java 8 с `jjs.exe`, её `classes/classes.jar` и `classes/libs.jar` с Javassist/ASM, ресурсы и правильный **предшествующий** `offline-patches.jar`. Всё это отсутствует в публичном репозитории.

Исходники — снимок последовательной разработки, а не один универсальный build. Некоторые сборщики ожидают JAR до добавления функции и откажутся или добавят дубли при повторном применении. Другие уже содержат финальные методы с более поздними зависимостями. Поэтому **нельзя запускать все `build-*.js` подряд на текущей игре** или ожидать сборки полного патча с нуля из этого снимка.

В опубликованной копии личные пути заменены на переменную `STALCRAFT_HOME`. Она должна указывать на корень отдельно установленной сборки. Рабочая директория — корень репозитория, поскольку пути исходников начинаются с `work/`.

Пример вызова отдельного этапа на подготовленном предшествующем JAR:

```powershell
$env:STALCRAFT_HOME = 'D:\Games\Stalcraft2019'
& "$env:STALCRAFT_HOME\runtime\java\bin\jjs.exe" `
  '-J-Dfile.encoding=UTF-8' `
  -cp "$env:STALCRAFT_HOME\classes\libs.jar" `
  work\build-equipment-stats.js
```

Этот пример требует версии **до** добавления `OfflineEquipmentStatsPane`. Результат создаётся в `work/`; пример не устанавливает его в игру. Сначала проверьте предпосылки конкретного скрипта, кандидат, состав JAR и тесты.

Общий порядок истории: кейсы → баланс/экономика → спавнер/исправление конфигураций → аномалии → предметы → исследование/исправление взаимодействия → выбор инвентаря/NEI → контейнеры → разделение/исправление сетки → артефакты по одному → эффекты артефактов → характеристики → вкладки → колонка экипировки. Это ориентир зависимостей, **не гарантированный рецепт чистой сборки**.

Установка проверенного кандидата: обычный выход из игры, резервная копия старого JAR, замена только `classes/offline-patches.jar`, полный перезапуск. Не устанавливайте тестовые адаптеры `*-test-only` в игру. Резервная копия JAR не откатывает уже произошедшие в игре изменения предметов/мира.

Скрипты `launcher/` приведены для объяснения настроенного запуска. `prepare-launch.ps1` предполагает присутствие комплектных `metadata` и мира `RegionsLocal`; исходная сборка их должна иметь. Сетевой адрес и запуск подключения друга намеренно не включены.
