# Исправление кейсов STALCRAFT 2019

Исправление установлено в `<GAME_ROOT>\classes\offline-patches.jar`.

## Проверка в игре

1. Запустить игру через свой `START.cmd` и зайти в мир.
2. Нажать Esc → «Кейсы», выбрать кейс и открыть. Цены: ящик эстета — 10 руб., обычный — 25 руб., особый — 50 руб., редкий — 75 руб., исключительный — 100 руб. Пополнить локальный рублёвый счёт можно через «Пополнить счёт» → «Добавить локально». При открытии меню-кейса рубли списываются сервером.
3. Для предмета-кейса открыть контекстное меню предмета в инвентаре и выбрать «Открыть». Расходуется один кейс и один ключ, если он требуется по настройкам предмета.

При заполненном инвентаре используется существующий механизм выдачи сборки: остаток может попасть в обычный инвентарь или выпасть возле игрока.

Другу нужно закрыть игру и заменить `classes\offline-patches.jar` в своей копии сборки приложенным файлом с тем же именем. Версии остальных файлов игры у вас должны совпадать.

## Что проверено

- JVM проверила все семь изменённых/добавленных классов.
- Реальный локальный каталог загрузил все пять кейсов, цены равны 10, 25, 50, 75, 100 руб. соответственно.
- 100 тестовых выпадений сохранили количество, состояние предмета и NBT-свойства; проверены копирование свойств, отсутствующий предмет и вероятность группы. Для этого теста использовался отдельный тестовый реестр предметов, он не включён в установленный файл.
- 209 остальных записей исходного файла исправлений сохранены без изменений.
- Исправлен краш `ArrayIndexOutOfBoundsException: 2` после второй награды: число этапов предпросмотра равно числу выпавших предметов, последнее получение закрывает окно без перезапуска. Повторные нажатия на завершённое окно игнорируются.
- Проверены 0–3 награды, 1–4 группы и повторные нажатия. Тест копирует методы кнопки в изолированный класс без графики; проверка предпросмотра заменяет только получение названия предмета тестовой строкой. Эти тестовые классы не включены в установленный файл.
- 100 выпадений из настоящей таблицы праздничного оружейного ящика дали по две награды и ровно два этапа предпросмотра. Использован отдельный тестовый реестр предметов.
- Полное открытие через игровой интерфейс ещё нужно проверить в игре. Автоматически игра не запускалась.

## Резервная копия и откат

Резервная копия прежних исправлений:
`<GAME_ROOT>\classes\offline-patches.before-cases-20261004-01.jar`.

Копия версии непосредственно перед исправлением краша:
`<GAME_ROOT>\classes\offline-patches.before-case-crash-20261004-01.jar`.

Для отката сначала полностью закрыть игру. Скопировать резервный файл поверх `classes\offline-patches.jar`, оставив оригинальную резервную копию на месте. Мир и файлы игроков не изменялись этим исправлением.

Актуальные исходники кейсов и баланса сохранены в `tools\offline-economy`; исторические версии — в `tools\offline-cases` и `tools\offline-balance`. Они предназначены для сопровождения, запускать их для обычной игры не нужно.
