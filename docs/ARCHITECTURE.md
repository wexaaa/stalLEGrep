# Устройство патчей

Изменения устанавливаются поверх существующего локального `offline-patches.jar`. Этот JAR стоит первым в classpath перед `classes.jar`, `libs.jar` и ресурсами. Скрипты Nashorn/JJS используют Javassist и местами ASM для добавления помощников, изменения выбранных методов и сохранения остальных записей архива.

| Помощник | Ответственность |
| --- | --- |
| `OfflineCases`, `OfflineBalance` | Каталог, локальное открытие, награды, баланс и цены. |
| `OfflineSpawner`, `OfflineSpawnerGui` | F7, сущности, аномалии, предметы и выбор инвентаря. |
| `OfflineResearch`, `OfflineResearchGui` | Станок, сессия взаимодействия и исследование. |
| `OfflineArtifactContainers` | Транзакции вложения/извлечения и подтверждение пакетов. |
| `OfflineInventorySplit` | Разделение и восстановление сетки при отказах. |
| `OfflineArtifactStacks` | Лимит 1 и безопасная миграция старых стопок. |
| `OfflineArtifactEffects` | Локальная активация, серверные свойства и лечение. |
| `OfflineCharacterStats`, `OfflineCharacterStatsPane` | Модель характеристик и панель персонажа. |
| `OfflineCharacterTabs` | Маршрутизация вкладок и синхронизация окон. |
| `OfflineEquipmentStatsPane` | Прокручиваемая колонка экипировки. |

Клиентский интерфейс не является источником истины: расход, права, баланс, предметы и исследования проверяются сервером. Операции инвентаря используют штатные ограничения сетки, глубокое копирование NBT и откат. Подтверждение повторного номера действия не означает повторное выполнение.

Локальная изоляция проверяется через `offline.world` там, где меняются региональные ограничения и новые панели. Не все исторические патчи имеют одинаковый механизм включения; нельзя произвольно переносить этот набор на официальный клиент.

Просмотр характеристик не записывает предметы или данные мира. Числа берутся из расчёта версии 2019; внешний вид современного интерфейса использован как образец, но современные формулы/значения не копировались.
