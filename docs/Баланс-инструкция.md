# Локальное пополнение баланса

Установлено в сборку `<GAME_ROOT>`.

После запуска через `START.cmd`: «Кейсы» → «Пополнить счёт» → ввести сумму → «Добавить локально».

Сумма прибавляется к рублёвому балансу магазина. Платёжные сайты не открываются, настоящие деньги не используются. Баланс «сб.» не изменяется. Окно остаётся открытым при обновлении баланса и после начисления; закрыть его можно крестиком.

Цены кейсов в меню: «Ящик эстета» — 10 руб., «Обычный кейс» — 25 руб., «Особый кейс» — 50 руб., «Редкий кейс» — 75 руб., «Исключительный кейс» — 100 руб. Цена списывается с серверного локального баланса один раз при открытии. При нехватке рублей награда не выдаётся и баланс не изменяется. Предметы-кейсы в инвентаре работают по прежним правилам: тратится кейс и, если требуется, ключ; рубли дополнительно не списываются. Остальные функции магазина этим изменением не исправлялись.

Баланс хранится в `PlayerPersisted.OfflineRealMoney` данных игрока на локальном сервере, отдельно для каждого игрока и мира. Обычное сохранение мира сохраняет и баланс. При завершении игры используй обычный выход, не принудительное закрытие процесса.

Допустимы положительные целые суммы, итоговый баланс не выше 2 147 483 647. Повторные запросы начисления в течение секунды игнорируются.

Автоматически проверены сложение, списание и недопустимые суммы, независимость счетов, запись/чтение настоящего NBT, цены настоящего каталога и проверка JVM. Настоящий обработчик ответа баланса проверен с тестовыми экранами: 10 обновлений не закрыли окно. Настоящие обработчики запросов проверены с тестовыми игроками и доставкой: верное списание, дубли запросов, нехватка денег, пополнение и ошибка выпадения до списания. Тестовые классы в установленный файл не включены. Остальные 219 записей предыдущей версии, включая исправления краша кейсов, сохранены без изменений. Полный интерфейс и реальное сохранение мира нужно проверить в игре; игра автоматически не запускалась.

Резервная копия перед этим изменением: `classes\offline-patches.before-balance-20261004-01.jar`. Для отката закрыть игру и скопировать этот файл поверх `classes\offline-patches.jar`, сохранив резервную копию. Файлы мира при установке не менялись.

Резервная копия перед исправлением окна и добавлением цен: `classes\offline-patches.before-economy-20261004-01.jar`.

Актуальные исходники находятся в `tools\offline-economy`. Другу для такого же интерфейса и цен нужно передать обновлённый `classes\offline-patches.jar`; на сервере-хосте также должна быть установлена эта версия.
