# STALCRAFT 2019 — локальные патчи

Исходники доработок локальной сборки STALCRAFT 2019, история исправлений и пользовательские инструкции. Проект предназначен для собственного локального мира и совместной игры с друзьями, а не для официальных серверов STALCRAFT.

В репозитории **нет самой игры, игровых ресурсов, сохранений, готовых JAR с классами игры и персональных сетевых адресов**. Нужна отдельно установленная совместимая сборка. Это архив разработки патчей поверх существующего `offline-patches.jar`, а не самостоятельный клиент или сервер.

## Что добавлено и исправлено

| Раздел | Результат |
| --- | --- |

| Кейсы | Открытие из меню и инвентаря, локальная выдача наград, расход кейса/ключа, исправление повторного открытия и вылета после второй награды. |
| Баланс | Пополнение игрового рублёвого счёта без платёжного сервиса, сохранение в данных игрока, исправление самозакрывающегося окна. |
| Цены | Ящик эстета — 10, обычный — 25, особый — 50, редкий — 75, исключительный — 100 игровых рублей. |
| Инструмент F7 | Вкладки сущностей, аномалий и всех зарегистрированных предметов; поиск, страницы, количество и выбор целевого инвентаря. |
| Спавн | Исправлены невидимые/непоявляющиеся мутанты и вылет при повторном спавне; передача конфигурации клиенту. |
| Аномалии | Отдельная вкладка с девятью типами, проверками места и серверных прав. |
| Исследование | Ставящийся в мире станок исследования артефактов, добавленный в F7 и NEI; исправлен конфликт открытия с CustomNPCs. |
| Контейнеры | Установка, замена и извлечение артефактов с сохранением NBT и серверным подтверждением. |
| Разделение стопок | Исправлен выбор ветки сетевого пакета и запись уменьшенной стопки в занятую сетку; сохранение количества и свойств. |
| Артефакты по одному | Лимит стопки 1; безопасное раскладывание старых стопок при наличии места. |
| Бонусы артефактов | Свойства исследованных активных артефактов применяются только из надетого контейнера; пересчёт без накопления бонусов. |
| Характеристики персонажа | Итоговые скорость, переносимый вес, выносливость, здоровье, лечение и защиты; исправлено открытие вкладки «Персонаж». |
| Колонка экипировки | Список характеристик в штатной колонке по образцу интерфейса: разделы, цветные значения, колесо и перетаскиваемый ползунок. |
| Лекарства и еда | Серверное лечение и временные бафы, расход одного предмета, перезарядка, снятие эффектов и сохранение в данных игрока. |
| Аптечка в HUD | Компактный слот под здоровьем: игровая иконка, количество, использование на C, таймер в секундах и полоса перезарядки. |

## Состояние проекта

Последний установленный этап — аптечка в HUD с использованием на C. Перед ним установлено исправление лекарств и еды. Изолированные тесты прошли; внешний вид с настоящей иконкой и применение в запущенной игре ещё требуют ручного подтверждения. Пользователь ранее подтвердил колонку характеристик, разделение стопок, артефакты по одному и действие артефактов в контейнере.

Отдельное изменение базовой скорости по последнему уточнению не устанавливалось: исходная база уже равна 100%, итоговая скорость учитывает вес и модификаторы. См. [открытые задачи](docs/ROADMAP.md).

## Использование установленной версии

Закрыть игру обычным выходом, сделать резервную копию `classes/offline-patches.jar`, установить совместимый проверенный патч и полностью перезапустить игру. JAR патчей должен идти первым в classpath. Для совместной игры версия патчей и остальные файлы сборки должны совпадать у хоста и друга. Готовый бинарный патч в этом репозитории намеренно не распространяется.

F7 открывает локальный инструмент. Блоки и станок выдавайте в «Обычный (блоки)», экипировку и артефакты — в «STALCRAFT». Исследуйте артефакт, вложите в контейнер и наденьте контейнер в слот спины.

C использует одну аптечку из инвентаря STALCRAFT. Слот под здоровьем показывает количество выбранного типа и время до следующего применения. Поддерживаются пять типов аптечек; еда, бинты и стимуляторы не выбираются вместо них. Зажатие C в локальном режиме больше не открывает старое меню избранного. Подробнее: [аптечка и HUD](docs/MEDKIT-HUD.md).

## Состав

- `work/*.methods.java` — добавленные методы, компилируемые Javassist; это не самостоятельные Java-классы.
- `work/build-*.js`, `work/fix-*.js` — исторические и последующие этапы изменения байткода.
- `work/test-*.js`, `work/verify-*.js` — изолированные проверки и контроль изменений.
- `launcher/` — подготовка запуска и образец локального запуска, без адреса друга.
- `docs/` — инструкции, технические пояснения и список незавершённых задач.
- `scripts/` — подготовка и проверка публикуемого исходного снимка.

Исходники используют обфусцированные имена конкретной сборки 2019. Совместимость с другими версиями не гарантируется. Проект не связан с EXBO; права на игру и её ресурсы принадлежат их владельцам. Публикация этих патчей не предоставляет прав на распространение самой игры.
