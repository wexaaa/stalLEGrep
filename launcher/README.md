# Образец локального запуска

Это архив настроенного запуска, не автономный установщик. В установленной игре `START.cmd` размещается в корне, а `prepare-launch.ps1` — в `tools/`; оба файла требуют остальных файлов исходной совместимой сборки. Адрес подключения друга не опубликован. Подробности — [в README](../README.md) и [ограничениях сборки](../docs/BUILD.md).
