# Подготовка публичного снимка

`prepare-source-snapshot.ps1` копирует только исходники и инструкции, заменяет личный корень игры переменной `STALCRAFT_HOME`, не включает бинарные файлы. `check-source-snapshot.ps1` проверяет состав текстового пакета. `check-javascript-syntax.js` выполняется через JJS из корня репозитория и компилирует синтаксис JavaScript без запуска сборщиков.
